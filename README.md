# Projet de Recherche Opérationnelle

Ce projet regroupe plusieurs applications de la recherche opérationnelle appliquées à des problèmes classiques, logistiques et réels.

## Sujets traités

1. Optimisation du transport  
2. Problème du voyageur (TSP)  
3. Files d’attente en centre hospitalier  

## Structure du projet

```text
PROJET-RO-TRANSPORT/
│
├── README.md
│
├── transport.py
├── heuristique_tsp.py
├── hospital_queue.py
│
├── rapport/
  └── rapport.pdf
```

## Installation

```bash
pip install -r requirements.txt
```

## Exécution des fichiers Python

```bash
python transport.py
python heuristique_tsp.py
python hospital_queue.py

```

## Objectif du projet

L’objectif est de modéliser et résoudre différents problèmes d’optimisation afin de minimiser les coûts, réduire les distances, améliorer les services et proposer des solutions efficaces.
